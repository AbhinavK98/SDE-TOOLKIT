## Revision in 5 minutes

- Strings are immutable in Python; use lists for repeated writes.
- For reversing, prefer two pointers.
- For words, decide whether multiple spaces should collapse.
- For prefix, stop at first mismatch.
- Edge cases: empty input, one word, trailing spaces, all same prefix.

## Revision in 1 minute

- Reverse range -> two pointers. Build output -> list + join. Prefix -> compare columns.
