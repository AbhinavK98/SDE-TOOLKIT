# Two Pointers And Palindromes Pattern Notes

## Revision in 5 minutes

- Valid palindrome -> skip non-alphanumeric, compare lowercase.
- One deletion -> on first mismatch, try skipping left or right.
- Reverse selected characters -> move each pointer until it finds a valid target.
- Longest/count palindrome -> expand around every center.

## Common mistakes

- Missing even-length centers.
- Continuing after multiple deletions in Valid Palindrome II.
- Comparing before skipping invalid characters.
- Slicing inside loops and accidentally increasing complexity.

## Revision in 1 minute

- Ends compare symmetry. Centers discover substrings.
