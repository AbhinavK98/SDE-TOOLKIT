# Sliding Window Substrings Pattern

## What is this pattern?

Maintain a contiguous substring with a left and right boundary while tracking
counts or constraints inside the window.

## When should I use this pattern?

- Longest substring with a condition
- Shortest substring containing something
- Fixed length substring score
- Anagram/permutation inside a string
- Count substrings satisfying character coverage
