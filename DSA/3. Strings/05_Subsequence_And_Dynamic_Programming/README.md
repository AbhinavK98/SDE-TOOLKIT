# Subsequence And Dynamic Programming Pattern

## What is this pattern?

Subsequence problems preserve relative order but may skip characters. Simple
versions use two pointers; counting or optimizing usually needs DP.

## When should I use this pattern?

- Check if one string appears inside another in order
- Count matching subsequences
- Delete characters to form a word
- Count distinct ways
- Longest common subsequence
