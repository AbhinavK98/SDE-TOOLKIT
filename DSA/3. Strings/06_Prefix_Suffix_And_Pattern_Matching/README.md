# Prefix Suffix And Pattern Matching Pattern

## What is this pattern?

Use prefix/suffix structure to avoid retrying matches from scratch.

## When should I use this pattern?

- Find a needle in a haystack
- Repeated substring structure
- Longest prefix that is also suffix
- Shortest palindrome by adding characters
- Match after repeating a base string
