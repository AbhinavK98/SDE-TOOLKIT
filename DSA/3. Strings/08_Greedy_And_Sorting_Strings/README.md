# Greedy And Sorting Strings Pattern

## What is this pattern?

Construct the best string by making a locally safe choice, often after sorting
characters or counting remaining supply.

## When should I use this pattern?

- Reorganize characters under adjacency constraints
- Remove digits/letters to make smallest result
- Compare strings for largest concatenation
- Partition so each character appears in one segment
- Custom order sorting
