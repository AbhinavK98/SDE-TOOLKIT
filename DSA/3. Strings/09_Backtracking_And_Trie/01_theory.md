# Backtracking And Trie Pattern Theory

## Core mental model

Backtracking builds a partial answer and chooses the next valid character or
piece. Trie stores dictionary words by prefix so invalid branches stop early.

## Recognition clues

- "all combinations"
- "all valid strings"
- "split into valid pieces"
- "prefix"
- "dictionary words on board"

## Important variations

- Choice tree generation
- Constraint pruning
- Memoized recursion for segmentation
- Trie insert/search/startsWith
- DFS board search with trie pruning
