# Backtracking And Trie Pattern

## What is this pattern?

Generate or search strings by exploring choices. Use a trie when repeated prefix
lookups are the bottleneck.

## When should I use this pattern?

- Generate all valid strings
- Restore possible IP addresses
- Word break / dictionary segmentation
- Prefix dictionary search
- Search many words on a board
