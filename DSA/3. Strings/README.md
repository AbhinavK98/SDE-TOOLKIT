# Strings Mastery Track

Welcome to the Strings track.

This folder continues the same pattern-first learning system used in Arrays.
Every pattern folder contains:

- A pattern-level README for intuition
- Theory with beginner explanations
- Cheatsheet for rapid revision
- Question files with brute, better, optimal approaches where useful
- Notes for interview recognition and edge cases

Start from `01_Basic_String_Manipulation` and move step-by-step. The goal is
not memorizing string questions; the goal is recognizing whether a problem is
frequency/hash based, two pointers, sliding window, subsequence DP, pattern
matching, parsing, greedy construction, backtracking, or trie.

## Recommended order

## Pattern map

| Pattern | Recognition clue | Core tool |
|---|---|---|
| Basic manipulation | reverse, trim, words, prefix | indexing and careful loops |
| Frequency and hashing | count, anagram, same mapping | dict / set / Counter |
| Two pointers / palindrome | compare ends, reverse parts | left-right pointers |
| Sliding window | longest/shortest substring with condition | expand + shrink window |
| Subsequence / DP | preserve order, count ways, LCS | pointers or DP table |
| Pattern matching | find prefix/suffix/needle | KMP / Z / rolling hash |
| Stack / parsing | nested, remove, decode, path | stack and state machine |
| Greedy / sorting | rearrange, compare order, construct max/min | local best invariant |
| Backtracking / trie | generate strings, dictionary prefix | recursion and prefix tree |
