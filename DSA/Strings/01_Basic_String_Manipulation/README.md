# Basic String Manipulation Pattern

## What is this pattern?

This pattern teaches direct string handling: scanning, reversing, splitting
words, comparing prefixes, and building answers.

## When should I use this pattern?

- Reverse characters or words
- Remove extra spaces
- Compare common prefix/suffix
- Extract simple string properties
- Problems mainly test indexing and boundary handling

## General Algorithm

1. Clarify if strings are mutable or immutable in the language.
2. Use a list of characters when many writes are needed.
3. Track boundaries carefully.
4. Build the final string once.
5. Dry run empty string, one character, spaces, and repeated words.
