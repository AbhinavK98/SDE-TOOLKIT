# Frequency And Hashing Pattern

## What is this pattern?

Use counts, sets, or mappings to compare string structure without checking every
pair of characters repeatedly.

## When should I use this pattern?

- Anagrams or permutations
- Count characters or words
- First unique/repeated character
- One-to-one mapping between characters or words
- Group strings by a canonical key
