# Two Pointers And Palindromes Pattern

## What is this pattern?

Move pointers from both ends or around a center to compare, reverse, or expand
over a string.

## When should I use this pattern?

- Valid palindrome
- Palindrome with one deletion
- Reverse vowels or words
- Longest palindromic substring
- Count palindromic substrings
