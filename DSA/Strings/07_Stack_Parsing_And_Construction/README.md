# Stack Parsing And Construction Pattern

## What is this pattern?

Use a stack or explicit parser state when strings contain nesting, cancellation,
or tokens that affect earlier characters.

## When should I use this pattern?

- Parentheses/brackets
- Remove adjacent duplicates
- Decode nested strings
- Simplify paths
- Basic expression parsing
