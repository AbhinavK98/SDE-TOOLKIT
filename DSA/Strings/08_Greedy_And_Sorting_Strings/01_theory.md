# Greedy And Sorting Strings Pattern Theory

## Core mental model

Greedy string problems require proving a local choice cannot hurt the future.
Sorting, frequency counts, stacks, or heaps often expose the correct local move.

## Recognition clues

- "smallest/largest possible string"
- "rearrange so no adjacent equal"
- "partition labels"
- "custom order"
- "minimum deletions"

## Important variations

- Monotonic stack for smallest number/string
- Max heap for most frequent character first
- Last occurrence boundary for partitions
- Comparator sorting for concatenation
- Used-frequency set for uniqueness
